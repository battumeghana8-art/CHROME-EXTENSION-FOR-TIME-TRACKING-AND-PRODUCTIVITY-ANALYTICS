# Description :
--> The Chrome Extension for Time Tracking and Productivity Analytics is a web browser extension designed to help users monitor, analyze, and improve their online productivity. In today's digital world, users spend a significant amount of time browsing various websites for work, education, entertainment, and social networking. However, most users are unaware of how much time they actually spend on different websites. This project addresses that problem by providing an automated solution that tracks website usage and generates productivity insights.

--> The extension continuously monitors the active browser tab and records the amount of time spent on each website. Whenever a user switches between websites, the extension calculates the time spent on the previous website and stores the information. This allows users to view detailed statistics about their browsing behavior and understand how their online time is distributed across different websites.

--> A key feature of this project is website classification. The extension categorizes websites into productive and unproductive groups. Productive websites include coding platforms, educational websites, documentation resources, online learning platforms, and professional tools. Unproductive websites include social media platforms, entertainment websites, and other sites that may distract users from their work or studies. Based on these classifications, the extension provides meaningful productivity analytics that help users evaluate and improve their daily browsing habits.

--> The project also includes a dashboard that displays tracked website usage in a simple and visually appealing format. Users can view the total time spent on each website, identify frequently visited websites, and monitor their productivity levels. The dashboard updates dynamically, ensuring that users always have access to their latest browsing statistics.

--> To support data management and future scalability, a backend server was developed using Node.js and Express.js. The backend handles API requests and provides a structured approach for storing and retrieving user activity data. This architecture allows the project to be expanded in the future with additional features such as user authentication, cloud storage, and advanced reporting.

--> Another important objective of this project is generating productivity reports. By analyzing the collected browsing data over a period of time, the system can provide weekly productivity summaries. These reports help users understand trends in their browsing behavior, compare productive and unproductive time, and identify areas where improvements can be made. Such analytics are particularly useful for students, developers, professionals, and remote workers who wish to manage their time more effectively.

--> The extension was designed with a focus on simplicity, usability, and performance. It runs efficiently in the background without affecting browser performance and provides users with accurate tracking information through an easy-to-use interface.
# Key Features :
1) Tracks time spent on different websites automatically.
2) Monitors active browser tabs in real time.
3) Categorizes websites as productive or unproductive.
4) Displays website usage statistics through a dashboard.
5) Calculates total productive and unproductive browsing time.
6) Stores browsing data for future analysis.
7) Supports weekly productivity reporting and analytics.
